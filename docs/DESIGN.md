## Visual Language
- Core visual signature: Strict grid alignment with dense information hierarchy and traffic-light badge system (success/warning/danger) for status
- Material & depth: Flat solid cards on a light grey shell (#F5F5F5) with distinct borders (#E0E0E0)
- Containers & buttons: Sharp corners or minimal rounding; clearly defined rectangular areas for data isolation
- Layout rhythm: Dense but structured data areas; oversized KPI typography used as visual anchors against neutral backgrounds

## Animation
- Interaction: Quick, subtle state changes on hover (e.g., slight background darken or border highlight)
- Scroll / transition: Minimal loading indicators for data refresh; no page-level entrance animations

## Forbidden
- No large flat color fills, including Hero/Banner/upload/action/input zones; Primary/Accent only as small focal accents
- Do not use rounded-corner cards / generic drop shadows / left color bars / gradient backgrounds as the core visual signature
- No looping decorative animations or page-level entrance effects that interfere with data reading

## Additional Notes
- All user-visible copy follows the user's language preference (English)
- KPI numbers must be extremely legible and use color coding (Accent/Warning/Danger) to convey priority
